# **App Name**: fb-badgers-app-0

## Core Features:

- File Upload: Upload files from your computer to your personal storage.
- File Download: Download files from your personal storage to your computer.
- File Deletion: Delete files from your personal storage.
- File Listing: List all files in your personal storage with details like name, size, and last modified date.
- Folder Management: Create, rename, and delete folders to organize your files.
- Collapsible Sidebar: Implement a collapsible left sidebar for easy navigation.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a sense of security and organization.
- Background color: Light gray (#ECEFF1), nearly desaturated blue to create a clean and unobtrusive backdrop.
- Accent color: Teal (#009688) as an analogous color, that adds contrast without distracting from the other elements, which may be used for active buttons, selected folders and highlights.
- Body and headline font: 'Inter', a grotesque-style sans-serif that has a modern, machined, objective, neutral look that suits both headlines and body text well.
- Use a set of simple, clear icons to represent file types and actions (upload, download, delete).
- Utilize a clean, card-based layout for displaying files and folders.
- Subtle transitions when navigating folders and displaying file information.
